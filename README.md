Proyecto: E-commerce Mueblería Hermanos Jota
Integrantes: Kevin Serrano, Gerónimo Bosco, Ivanna Valle, Fernando Romero, Jeffrey Valverde.

Tecnologías Utilizadas: React, Node js, Express.js Y MongoDB

Link del frontend en vercel: https://jota-itba.vercel.app/

Instalación local:
1- Clonar proyecto desde https://github.com/kevinserrano01/jota-itba.git o https://github.com/fromero34/jota-itba
2- Abrir terminal y entrar a la carpeta del backend con "cd backend"
3- Hacer npm install
4- Hacer npm start
5- Abrir otra terminal y hacer "cd frontend"
6- Hacer npm install
7- Hacer npm run dev
8- Usar local host por defecto o crear archivos .env en caso de querer usar otros parámetros
